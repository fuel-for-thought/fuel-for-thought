# Fuel for Thought

Fuel for Thought is an ICS 314 project for finding affordable, healthy food near the University of Hawaiʻi at Mānoa. Milestone 1 uses sample listings and community posts.

## Develop

Use Node.js 24. The site has no external package dependencies.

```sh
npm run build
npm run dev
```

Open the Community page on port 3000. Rebuild after editing the page templates or assets. The footer links to the project home page.

## Deploy

Import this repository in Vercel and deploy the main branch. The checked-in Vercel configuration runs the build, publishes `dist`, and enables extensionless URLs. Check the Community page, its navigation, and the screenshots on the project home page on the deployed site.

See the [Milestone 1 checklist](docs/m1-checklist.md) for project tracking and links.
